◇
Built with privacy in mind.
The site downloads its code and Python runtime, then processes your PTX and selected audio metadata in browser memory. No session upload is required.
Current limitations. PTX2RPP v1.2.0 doesn't convert plugins, routing, automation or variable tempo maps. Audio metadata is used instead of full audio in the browser, and AIFF durations aren't read. Always verify converted sessions in REAPER.
