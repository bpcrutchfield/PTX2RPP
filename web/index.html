◇
Local conversion, by design.
The Python runtime and converter code are downloaded from the web. Your selected PTX contents and audio metadata are processed in browser memory. No session data is intentionally sent to a server.

      
Prototype limitations: a browser cannot automatically place the result beside your original session; WAV metadata is used in place of actual audio, so some healing and media-dependent behavior may differ from desktop PTX2RPP. AIFF audio can be matched by name, but its frame count is not read. Tempo maps, plugins, routing and automation are not supported by v1.2.0.
